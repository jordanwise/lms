## How to use with Claude Code

1. Copy a Figma frame link from the table above
2. Prompt Claude Code:
   ```
   Implement the design at [PASTE LINK] using React + Tailwind.
   Use components from web/src/components/ui/.
   ```
3. For Android: ask for "Jetpack Compose with Material 3"
4. For iOS: ask for "SwiftUI views"
