# How the game works

A game is created, with fee, leagues chosen etc. The game creator shares the game details and other players join by either opening a shared link or using the game pin and paying the fee.

The game creator must then add rounds to this game.

The game creator chooses a particular matchday of a league/(s) as a round.

Each player must then choose a team from the fixtures list(s).

If the team wins, the player advances to the next round.

If the game is postponed, the player advances to the next round. However, they will need to be successful on both choices when the rescheduled game is added to another match day.

The player cannot pick the same team twice througout a game. 

A game finishes when there is only one player left, unless split pot has been selected at the start of the game

A split pot shares the prize fund between the last remaining players all players fail to select a winning team

If rollover was selected, this activates when there wasn't a singular last player standing (eg, the same situation as when the split pot activates). All the participants from the start repay the original admision fee and the game restarts but with the prize now doubled (as it has the previous unclaimed prize fund already.)
